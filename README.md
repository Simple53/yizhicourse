# 公务员 / 事业编 5s 口诀秒杀大招课 在线学习平台

在线访问地址：https://simple53.github.io/yizhicourse/

本仓库用于托管《公务员 / 事业编 5s 口诀秒杀课》的轻量化在线学习网页，通过 GitHub Releases 托管高清视频课与讲义资料，并通过 GitHub Pages 提供极简、流畅的在线播放与复习体验。

---

## 核心特性

- **纯净设计**：严格采用极简风格界面，使用无损 SVG 矢量图标，杜绝冗余元素与 Emoji 装饰。
- **Release 托管**：所有大体积课程视频（MP4）与配套课件以版本标签（Releases）的形式分类存储，不占用 Git 仓库代码体积。
- **全功能播放器**：
  - 支持快捷键控制（空格暂停/播放，方向键快进/快退，中括号快速切换上下节）。
  - 支持多档播放倍速调节（1.0x / 1.25x / 1.5x / 2.0x）。
  - 课件文档专属预览与一键下载卡片。
- **学习进度记录**：本地浏览器（LocalStorage）自动记忆播放进度、已学课时标记与上次观看课时。
- **双播放源热切换**：支持 GitHub Release 源与高速备用源自由切换，确保在资产上传过程中亦可即时播放。
- **深色模式**：支持明暗双色主题自适应与手动切换。

## 资产上传与同步脚本

如果需要将本地下载好的音视频与讲义文件同步上传至 GitHub Releases，可使用内置的自动化脚本：

```bash
# 上传全部模块的资产
python upload_releases.py

# 仅上传指定模块（例如仅上传模块 6 资料大礼包）
python upload_releases.py 6
```

## 部署说明

1. 进入 GitHub 仓库设置界面：`Settings -> Pages`。
2. 在 `Build and deployment` -> `Source` 中选择 `Deploy from a branch`。
3. Branch 选择 `main` 分支，路径选择 `/ (root)`，点击 `Save`。
4. 部署完成后即可通过 https://simple53.github.io/yizhicourse/ 访问。
