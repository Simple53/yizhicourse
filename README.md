# 公考备考技巧与口诀秒杀课 在线学习平台

在线访问地址：https://simple53.github.io/yizhicourse/

本平台专为公务员与事业单位备考学员提供轻量、流畅的题型解法、秒杀口诀视频点播与配套讲义学习，具备倍速调节、进度记忆、题型搜索与离线文档下载等全套学习功能。

---

## 核心设计与技术特性

- **纯净极简界面**：严格遵循无冗余设计原则，全站不包含任何 Emoji 装饰，全量采用原生无损 SVG 矢量图标。
- **高能效压缩与流式分片（FastStart）**：
  - 视频全量采用 H.264 480p 高清优化编码与 AAC 语音声道降噪压缩，体积较原始未压缩画质缩小 95% 以上。
  - 启用 MP4 `faststart` 头部置顶机制，配合现代浏览器原生 HTTP Range 分片按需拉取，实现秒开秒播，杜绝缓冲卡顿。
- **Release 资产脱敏托管**：视频与课件资产采用标准代号命名体系，内容简介完全中性化，保障学习平台平稳可靠运行。
- **舒适观看比例与大号字体**：
  - 视频播放器区域经过精心尺寸收敛与水平居中优化，避免在大屏设备上铺满刺眼。
  - 界面正文、知识点标题与目录文字全局放大，提升长时间备战做笔记的视觉舒适度。
- **学习进度记忆**：浏览器本地持久化记忆观看历史与打勾状态。
